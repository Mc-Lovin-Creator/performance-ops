# Rules for the Emergent agent

Paste-in prompts tell the agent to read this file first. Keep it short and strict.

1. **This repo is complete and tested. Do not rewrite, refactor, restyle or convert it.** No new React components, no new frameworks, no "improvements" unless the prompt asks for that exact change.
2. **The app lives in `app/src/`.** `frontend/public/index.html` is generated by `python3 app/build.py` (it runs automatically before `yarn start` and `yarn build`), so never edit the generated file.
3. **Services:**
   - Backend: run from `backend/` with `uvicorn server:app --host 0.0.0.0 --port 8001`.
   - Frontend: run from `frontend/` with `yarn start` on port 3000.
   - All API routes are under `/api`.
4. **Python dependencies:** use `backend/requirements.txt` as it is. Do not add packages without saying why.
5. **Secrets:**
   - Never create, print, log or commit secrets.
   - `JWT_SECRET`, `FIELD_KEY`, `SETUP_TOKEN`, provider client secrets, `WEAR_CRON_KEY` and `GARMIN_PUSH_KEY` are typed in by the owner.
   - If one is missing, stop and say which one.
   - Never set a default or test value.
6. **No default accounts, passwords or codes.** Accounts are created only through `scripts/first_lead.py` and the Account screen.
7. **No real patient data.** It is demo data only until the owner says stage 6 is signed off.
8. **No clinical data in any AI prompt or third-party service.**
9. **Saving work:** if you change any file, use **Save to GitHub** on a new branch named `emergent/<yyyy-mm-dd>-<short-name>`, never on `main`. Then list every file you changed and why.
10. **Before saving:** run `npm test` (or at least `python3 app/build.py`, `node tests/static_checks.mjs` and `cd backend && python -m pytest -q`) and report the result.
11. **If something fails:** report the exact error and stop. Do not work around security checks (two-step sign-in, consent, roles, CORS, encryption).
